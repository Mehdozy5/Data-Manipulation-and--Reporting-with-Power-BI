# Data Manipulation and Reporting with Power BI (Zomato Dataset)

A multi-page interactive Power BI report analysing global restaurant data from Zomato, 
a restaurant aggregation and food delivery platform, covering 9,551 restaurants worldwide.

## Overview
Built an interactive report allowing users to explore restaurant data by country and city, 
with drill-down filters for online delivery availability, table booking, and rating. 
The report covers restaurant distribution, cost, and ratings across multiple regions 
(Asia, Europe, North America, Africa, Oceania).

## Features
- **Global overview page:** world map showing restaurant distribution by region, plus 
  headline KPIs — 9,551 total restaurants, aggregate rating of 3.0, and average cost for 
  two of 1,199.21 — alongside a top-5 average-rating-by-restaurant chart
- **Country/city drill-down page:** filterable by country, city, online delivery 
  availability, table booking, and rating colour band, with a treemap visualising 
  restaurant share by name and colour-coded gauge charts for average cost and average rating
- Restaurant-level detail table showing cuisine type and address

## Tools
Power BI (DAX, data modelling)
